# Smath 2.0.1

本次更新集中在「复杂分支对话」的拓扑图：拖动手感、缩放、以及节点较多时的画布整理。

## 拖动

- **不再需要长按**：手指移动超过系统 touch slop 就直接拖动节点，松手即落位。
- **严格跟手**：节点位移改用「手指相对按下点的绝对位移」计算，而不是逐帧累加增量，系统 slop 不会再吃掉第一段位移，因此松手位置等于手指走过的距离。
- **只动一个节点**：拖动只移动被按住的那个节点，其它节点（包括它的下游）都不会跟着动，节点关系不变。想重新排布请用「一键整理画布」。
- **长按查看详情**：长按节点不移动会打开「节点详情」，可以看完整问题与 AI 回答，也可以跳到该节点。
- **单击多选**：单击切换选中，选中 1 个可新建分支，选中 2 个及以上会变成「合并建分支」。

## 画布缩放与归位

- 新增**双指捏合缩放**，缩放范围 0.35×–2.5×；单指在空白处拖动为平移。
- 修掉**双指缩放回弹**：`calculateZoom()`／`calculatePan()` 返回的是「相对上一个事件」的增量，之前按「起点 × 增量」计算，每帧都会被拉回起点附近；改为在当前值上累加，捏合过程连续不抖。
- **以两指中点为中心缩放**：按 `pan' = pan + 中点 × (1/新 zoom − 1/旧 zoom)` 修正平移，两指之间的内容始终停在两指中间，不会以画布左上角为轴把人甩出去。
- 修掉**松手后再点会飞走**：双指结束后剩下一根手指时，把单指基准点重设到那根手指的当前位置（并重新做一次命中测试），不会再拿第一根手指按下时的坐标去算位移。
- 右上角「归位」按钮（准心图标）会把整张图**缩放到合适大小并居中**：只缩小不放大，并按 1.06 倍留出边框余量，节点再多也能一屏看全。
- 命中测试改为**从上往下**（后绘制的卡片在上层），重叠或相邻时点中的永远是眼睛看到的那一张，修掉「有的节点点不动、拖不了」。

## 主界面跟随分支

- 拓扑图底栏新增「跳转」按钮（选中 1 个节点时可用）：跳到该节点后，主界面只显示从根节点到该节点这一条链路，随后的提问会在这个节点之后新建分支。
- 停在「已经有下游」的节点上时，输入框上方会提示「正在从 #n 继续」，这种分支是常态，因此提示条**不带取消按钮**；只有多选合并建立新分支时才出现 ✕。

## 一键整理画布

- 拓扑图右上角新增 ✨「一键整理画布」按钮（在「归位」左边）。
- 点击后清空手动位置，按层级重新排布：同一深度同一行，同层按创建顺序横向排列，整理完自动归位。
- 修掉了「复杂合并图被排成一条直线」的问题：像 `1-2-3-4` 再把 `2` 和 `4` 合并这种「回卷合并」，合并出来的节点会落在最深父节点所在行的右侧，图上能看出分叉，而不是接在链尾。
- 如果某张图的 `parentIds` 首尾相连成了环（数据异常），整理会直接提示「这张图的合并关系成环了，暂时无法自动整理」，不会把图排乱。

## 其它

- 节点卡片底色改为不透明，去掉了此前「正在编辑」节点上透出阴影的灰底；「正在编辑」改用 2dp 主色边框 + 右上圆点表示。
- 版本号：2.0.1（versionCode 16）。

## 已知限制

- 双指缩放需要在真机上用两根手指操作，本版本通过 adb 注入的单点手势无法自动化验证，逻辑按 Compose `calculateZoom` 实现。
- 画布不保存缩放倍数，只保存每个节点的位置；重新打开拓扑图会按归位逻辑重新计算视野。
