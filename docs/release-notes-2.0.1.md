# Smath 2.0.1

本次更新集中在「复杂分支对话」的拓扑图手感和画布整理。

## 拓扑图拖动

- **不再需要长按**：手指移动超过系统 touch slop 就直接拖动节点，松手即落位，位移按手指实际移动量换算，不再出现「松手位置和最终位置不一样」。
- **连带下游一起动**：拖动某个节点时，它会带着自己所有下游节点（子分支）一起平移，上游和其它分支保持原地。判断依据是各节点的 `parentIds`，所以合并出来的节点会跟随它的所有上游来源。
- **长按查看详情**：长按节点不移动仍然打开「节点详情」，可以看到完整的问题与 AI 回答，也可以直接跳到该节点。
- **单击多选**：单击切换选中，选中两个及以上节点后底部按钮变成「合并建分支」。

## 一键整理画布

- 拓扑图右上角新增 ✨「一键整理画布」按钮（在「适配画布」左边）。
- 点击后清空所有手动位置，按树形重新分层排布：同一深度对齐同一行，同层节点按叶子顺序横向展开，整理完自动把整张图居中到可视区，并提示「画布已整理」。
- 之后仍然可以手动拖拽微调；只有再次点整理才会重排。

## 其它

- 分支拓扑图的节点卡片底色改为不透明，去掉了此前「正在编辑」节点上透出阴影的灰底；「正在编辑」改用 2dp 主色边框 + 右上圆点表示。
- 版本号：2.0.1（versionCode 16）。
