# Smath 2.2.0

> 安装包：`dist/Smath-2.2.0-release.apk`（12,998,017 字节，SHA-256 `0A32BDE8B33CD6AE2C2695CA25676AFA631D46946580CC2DDAD0159F852D5995`）
> 版本：versionCode 19 / versionName 2.2.0，minSdk 26，targetSdk 35

## 这一版做了什么

### 1. 主界面：思考与滚动
- **「展开/收起思考」不再放在输入框下方**，改为思考区块自己的标题行——点一下展开，展开后右上角悬浮一枚「收起思考」，随时收起。
- 思考区块**去掉了外框和底色**，只留一行小字：`正在输出 · 12s` / `总用时 12 秒`，折叠时仍显示最后一行的预览。
- 计时口径修正为**整个输出过程**（思考 + 工具调用 + 正式回答）的总耗时，不再是「思考用时」。
- 修掉「异常跳转」：贴底改用逐像素 `scrollBy` 逼近底部，不再用 `scrollToItem` 硬对齐某一项的顶部；同时保留「用户一动手就彻底交出滚动权」与视口上方高度补偿。

### 2. 多步工具调用（可在思考中调用）
- 模型**在思考过程里也可以调用工具**；一次回答最多 8 轮工具往返，结果回传后可以继续调用、多次计算。
- 支持的工具：计算器、线性代数计算器、绘图（含参数方程）、lean 编译。
- 流式过程中会在回答上方显示工具轨迹（勾/叉 + 名称 + 命令摘要），样式参照 DeepSeek Harness。
- 提示词明确要求：**思考里调用的工具用户要展开才看得到，所以正文里必须再给出一次工具块或把结论写全**——避免「图只留在思考里」。

### 3. 新增 lean 编译 Agent（局域网）
- 仓库新增 `tools/lean_server.py`：只用 Python 标准库的 HTTP 服务，`GET /health` + `POST /v1/check`，用 `X-API-Key` 鉴权。
- 手机端在「设置 → 特殊 Agent → lean 编译 Agent」里填**服务地址**与 **API Key**；**没填或没开就点不动开关**，并提示「需要lean编译工具」。
- 开启后模型可以写 `[$$lean_start$$] … [$$lean_end$$]` 代码块，App 交给电脑上的 lean 真正编译，把 stdout/stderr 回传给模型；连不上或编译不过都会变成中文结论，模型据此修正。
- 电脑端安装 lean 三选一：`pip install lean`、`elan`、官方 zip；自检命令：
  ```bash
  python tools/lean_server.py --self-test
  python tools/lean_server.py --key 你的密钥
  ```
  如果 lean 只能用模块方式启动，用 `--lean "python -m lean"`。

### 4. 预设风格门控
- 「多调用数值检验」改名为**「多用计算器agent」**；新增**「鼓励使用lean编译agent」**。
- 两者都**只在对应 Agent 开关打开时才可选**（计算器/线性代数开关、lean 编译开关），未开启时胶囊置灰并给出提示。

### 5. 清理
- 删除全部宣传片过程文件与产物（视频、封面、配乐脚本、录制截图、分镜文档），仓库只保留源码、发布说明与安装包。
- 本地 git tag 只保留最新的 `v2.0.1`，其余历史 tag 已删除。

## 已知限制
- 双指缩放仍需真机手动验证：adb 只能注入单指事件，无法自动化。
- lean 编译只做单文件类型检查，不负责 `lake` / mathlib 依赖。
- 思考内容里的工具块在折叠状态下不显示（这正是提示词要求正文复述一遍的原因）。
