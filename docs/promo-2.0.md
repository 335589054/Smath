这一次不使用任何真机截图：全部画面由 `tools/promo/make_promo2.py` 用 Pillow 逐帧绘制，
一次渲染 1444 帧（1920×1080 / 30fps / 48.12s），再由 `tools/promo/add_music2.py` 合入配乐。

## 制作要点

- 全部元素都是矢量/位图绘制：渐变底、径向辉光、点阵网格、白卡 + 真实投影（由 alpha 生成高斯阴影）、贝塞尔连线。
- 动画曲线统一用 `ease_out` / `ease_in_out` / `ease_back`，节点入场带轻微回弹，避免线性位移的生硬感。
- 帧直接通过管道喂给 ffmpeg（`-f rawvideo`），不落地 1444 张 PNG，渲染一遍约 3–5 分钟。
- 配乐复用 `神椿市協奏中。 - ゆりかご (Instrumental).flac`：取 91.98s 起 48.12s（段落硬起，落在小节线上），
  `volume` 增益 +4.7→3.9 dB（受真峰值 −1.2 dBTP 约束）、0.35s 淡入、2.8s 淡出、`alimiter` 兜底，
  AAC 320k；视频流 `-c:v copy` 不重编码。

## 重建

```powershell
$py = "C:\Users\33558\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py tools\promo\make_promo2.py --video dist/Smath-promo2-1080p.mp4
& $py tools/promo/add_music2.py --video dist/Smath-promo2-1080p.mp4
```

只看某几帧：

```powershell

```
