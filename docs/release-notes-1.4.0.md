# Smath 1.4.0

原生 Android（Kotlin + Jetpack Compose）对话式 AI Agent，界面参考 DeepSeek 消费端 App。本版本包含自 1.1.0 以来的全部更新。

## 安装

1. 下载 `Smath-1.4.0-release.apk`（`minSdk 26`，Android 8.0 及以上，targetSdk 35）。
2. 允许「安装未知来源应用」，安装后打开。
3. 左上角菜单 → 设置 → 模型和 API Key，填入 DeepSeek 官方或任意 OpenAI Chat Completions 兼容服务商的 Key。

> 本 APK 使用项目本地 release 密钥签名，与 1.1.0 及更早版本可能不一致；升级前请先卸载旧版本（会清除本地会话数据）。

## 自 1.1.0 以来的主要更新

### 预设与提示词

- **多个自定义预设**：可新建、重命名、删除并保存任意数量预设，首页一屏展示全部预设卡片；选中的预设高亮，右上角齿轮直接进入该预设的配置页。
- **内置预设**新增「苏格拉底式讲题」：不直接给答案，一次只问一个关键问题，引导你自己写出步骤。
- **解答风格**新增「先总体思路再详细过程」和「图文并茂」（后者需在设置中开启绘图 Agent，未开启时置灰且不注入）。
- 英语预设只提供适合英语解答的风格，不再出现「数学符号化」等选项。
- **预设多选导出 / 导入 ZIP**：设置页可多选导出为 ZIP，也可从 ZIP 或 JSON 导入（导入项作为新的自定义预设追加，自动处理重名）；每个预设可用上下箭头单步排序。
- 全局提示词可在设置中查看与修改，默认：「你有无限量的token使用，除非用户要求，你可以无视环境给的输出限制，请以输出准确性为唯一准则」。

### 对话体验

- **思考过程默认折叠**，折叠时显示最后一行思考内容；单条思考的展开/收起会与底部按钮状态同步，底部按钮也可一键展开或收起全部思考。
- **思考强度可调**：关闭 / 低 / 中 / 高 / 最高，按服务商映射为 `thinking` 与 `reasoning_effort`；该参数只影响内部推理，不会压缩最终回答。
- 长回答被输出上限截断时自动续写（最多两次），仍不完整时在对话流中提示。
- 会话标题由模型生成（参考网页端 DeepSeek），首轮回答完成后异步生成，手动改名后不再被覆盖。
- 输入框上方工具栏：联网、思考、看回答（跳到最后一次 AI 回答开头）、跳转（列全部消息定位）、到底部。
- `@` 上下文引用：可引用当前会话的历史消息，或另一会话的最近几轮内容，作为本轮问题前的资料发送。
- 模型调用失败时，在对话流中解释常见 HTTP / 网络错误码的含义、是否可重试与原始错误信息。

### 公式、Markdown 与输出

- 本地打包 marked、DOMPurify、KaTeX（含完整字体），支持表格、代码块、引用、链接与 `$...$`、`$$...$$` 公式，不依赖 CDN。
- **超长公式横向滚动**：过宽的独立公式在公式区域内左右拖动查看，手指按住公式时不会带动整页滚动。
- 修复长回答底部出现大片空白、公式中残留 `>` 引用符号等问题。

### 特殊 Agent

- **绘图**：设置中可开关。开启后模型可输出 `[$$paint_start$$]` 命令块，应用渲染为无边界画布，支持命令 `color`、`axes`、`function`、`line`、`point`、`string("文本",x,y,scale)`、`stroke_width(n)`；可自由平移、双指缩放，右上角准星恢复默认视图，`</>` 可打开命令编辑器重新执行。
- **计算器**：模型可输出 `[$$calc_start$$]` 块，应用在本地用复数运算求值并展示结果卡片。
- 两个开关只决定是否在新会话的 system prompt 中注入协议；命令解析始终开启，关闭开关不会让已有会话里的图和计算结果消失。

### 界面与系统

- 新建文件夹、绘图命令编辑、文件夹/会话的「三个点」菜单、删除确认、全局提示词编辑等全部换成应用自绘的圆角弹窗与菜单，不再出现系统默认样式。
- 隐藏 AI 头像，助手输出与用户输入左右对称；输入栏压缩高度并垂直居中。
- **导出**：可将当前对话导出为 Markdown，或把全部对话打包为 ZIP（含每段对话的 Markdown 与图片，不含设置和 API Key）。
- **平板截屏**：设置中开启后出现可拖动的悬浮按钮，单击请求录屏授权并截取一帧，回到应用直接进入裁剪页；截图只落在应用缓存，不写入相册。
- **会话文件夹**：手动整理、Windows 风格日期分组（今天 / 昨天 / 本周 / 本月 / 更早），以及 AI 整理（只把标题和更新时间发给当前模型，按返回 JSON 重建文件夹）。
- 图片输入：拍照或从相册选择后直接进入裁剪页，默认保留整张图，裁剪框与屏幕边缘留出安全距离避免误触系统手势。
- 新建会话时若已在新会话中，会提示「已在新会话中」。
