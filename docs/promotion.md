## 二、宣传片构思

### 定位

一句话：**“不止会聊天，还会画图、会算、会讲题的数学 AI 学习搭子。”**
主角不是模型参数，而是「把一道题真正讲清楚」的过程。

### 版本规划

| 版本 | 时长 | 画幅 | 用途 |
| --- | --- | --- | --- |
| 主片 | 45–60s | 16:9 横屏 1080p | 官网页头、GitHub Release 说明、B 站/YouTube |
| 竖屏短片 | 15s | 9:16 1080×1920 | 抖音/小红书/视频号 |
| 平板演示 | 20s | 16:10 | 强调平板截图与无限画布 |

### 核心叙事（三段式）

1. **痛点（0–6s）**：AI 给的答案“看起来对，但看不懂、公式被截断、图也没有”。
2. **解法（6–38s）**：Smath 把「预设 + 学段 + 风格 + 绘图/计算器」组合成一套讲题流程。
3. **召唤（38–50s）**：开源、可换模型、Key 存本机 → 下载 APK。

### 分镜表（主片 50s）

| 时间 | 画面 | 屏幕文字 / 动效 | 旁白 |
| --- | --- | --- | --- |
| 0.0–3.0 | 黑底，一行被“截断”的公式从中间被切断，右侧留白 | 「答案没写完？」逐字出现，轻微抖动 | 你有没有遇到过，AI 讲到一半就停了？ |
| 3.0–6.0 | 切到 Smath 首页，五个 Agent 预设卡片依次点亮，选中「数学问题」 | 「先选讲法，再讲题」 | 在 Smath，先选授课方式。 |
| 6.0–12.0 | 输入一道题（高中导数），点发送；思考块折叠成一行小字预览 | 思考条：`已思考 6.2s · 先看定义域…` | 它先自己想，不打扰你。 |
| 12.0–20.0 | 答案缓慢下滚，公式横向拖动（手指按住公式左右拉），高亮“关键变形” | 「公式不截断，可以左右滑」 | 长公式不会断，也不糊。 |
| 20.0–27.0 | 切到绘图 Agent：`function("sin(x)")` 画布出现，双指缩放，坐标轴跟随 | 「无限画布，随手缩放」 | 函数图像、几何关系，直接画给你看。 |
| 27.0–32.0 | 计算器块展开：`(3+4i)*(2-i)` → 结果高亮 | 「复数也能算」 | 需要精算时，它自己算，不用你验算。 |
| 32.0–38.0 | 抽屉：AI 整理文件夹，会话自动归入「导数」「三角函数」 | 「会话自动归档」 | 做过的题，自动分好类。 |
| 38.0–43.0 | 平板横屏：悬浮「截」按钮拖到题目上，单击 → 裁剪页 → 追问 | 「截图即提问」 | 拍不到？截屏也行。 |
| 43.0–47.0 | 设置页：模型和 API Key（DeepSeek / ChatGPT），Key 打码 | 「你的 Key，你的模型」 | 模型自己选，Key 只留本机。 |
| 47.0–50.0 | 图标 + 一行标语 + 仓库地址 | 「Smath · 开源」 | Smath，把题讲明白。 |

### 竖屏 15s 版

只保留三个高光镜头，每个 4–5s：
1. 预设卡片点亮 → 2. 长公式左右拖动（最有记忆点）→ 3. 绘图画布缩放 → 落版二维码。

### 视觉与音乐

- 主色沿用应用品牌蓝 `#4D6BFE`，背景用浅灰 `#F7F8FA`，深色模式镜头各占一半，形成节奏对比。
- 转场：同形状遮挡（圆角卡片放大成下一镜背景），避免花哨 3D。
- 音乐：100–110 BPM 的轻电子/钢琴，第 12s 与第 32s 各有一个重音，卡在“公式拖动”和“AI 整理”两个动作上。
- 字幕：思源黑体 Bold，白字深色描边；公式镜头不叠字幕，让 LaTeX 自己说话。

### 拍摄素材清单（按镜头逐条录）

1. 首页五个预设 + 选中高亮 + 齿轮入口
2. 高中导数题：完整回答、思考折叠态、展开态
3. 超长公式：横向拖动 3 次，慢速回放
4. 绘图：`sin(x)`、`x^2/4`、文本标注、缩放与重置视图
5. 计算器：复数、`sqrt(2)`、三角函数
6. @ 上下文引用：引用上一条回答再提问
7. 文件夹：AI 整理前后对比、手动移动
8. 拍照 → 裁剪（默认全选）→ 发送
9. 平板：悬浮“截”按钮、单击截图、裁剪页、追问
10. 设置：模型切换、思考强度、预设导入导出 ZIP、全局提示词
11. 导出：Markdown 单条 + ZIP 全部（可选作片尾彩蛋）

### 录制与后期流程

1. AVD 内安装 `app-release.apk`，用真实 API Key 提前跑好两条会话，避免现场等流式输出。
2. `adb shell screenrecord --size 1080x2400 --bitrate 12M --time-limit 180` 分段录制，每段只做一个动作。
3. `ffmpeg` 裁剪 + `setpts` 做 0.6×/1.6× 变速，关键动作处加 4 帧缓入缓出。
4. 片头片尾用同一套圆角卡片做模板；屏幕文字在剪辑软件里重新排，避免录制分辨率下的锯齿。
5. 导出：H.264 / 1080p / 30fps / CRF 18，音频 AAC 192k。
