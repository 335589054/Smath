# Smath 2.1.1

这一版只做修复，功能与 2.1.0 相同。

## 修掉的问题

- **上下滑动时页面被拽走**：打开会话后原来会在 900ms 内反复「贴底」，期间用户一滑动就被拉回底部（表现为「滑到某个位置突然回到底部、卡一下」）。现在只要检测到用户开始拖动就立刻停止自动贴底，绝不会再抢滚动。
- **向上翻跳回上一条开头**：Markdown / KaTeX 由 WebView 渲染，条目被列表回收后重新出现时高度会从很小重新长起来，列表跟着重新定位。现在按消息缓存已渲染高度，并在视口上方条目高度变化时按差值补偿滚动位置，翻动历史消息不再跳动。
- **公式编号压在公式上**：模型常用 `\tag{1}` 给公式编号，KaTeX 会把编号绝对定位到行末，容器一窄就叠在公式尾巴上（截图里「= (1)」重叠就是这样，红色则是 KaTeX 的报错色）。现在渲染前把 `\tag{1}` / `\tag*{1}` 改写成公式内的 `(1)` / `1`，随公式一起排布、一起横向滚动；另外加了一条 CSS 兜底，漏网的编号也不会再绝对定位压字。

- 双指缩放只能用真机手试，adb 无法注入多指手势。
