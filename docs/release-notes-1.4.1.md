# Smath 1.4.1

原生 Android（Kotlin + Jetpack Compose）对话式 AI Agent，界面参考 DeepSeek 消费端 App。本版本是 1.4.0 的修复与体验更新。

## 安装

1. 下载 `Smath-1.4.1-release.apk`（`minSdk 26`，Android 8.0 及以上，targetSdk 35）。
2. 允许「安装未知来源应用」，安装后打开。
3. 左上角菜单 → 设置 → 模型和 API Key，填入 DeepSeek 官方或任意 OpenAI Chat Completions 兼容服务商的 Key。

> 与 1.4.0 使用同一 release 密钥签名，可直接覆盖安装，会话数据保留。

## 本次更新

### 添加自定义服务商

- 设置页「添加自定义服务商」改为独立表单弹窗，不再把 `https://api.example.com/v1`、`model-name` 之类的示例值直接填进输入框。
- Base URL 可省略协议，保存时自动补 `https://` 并去掉结尾斜杠；名称留空时用「自定义服务商」。
- Base URL 或模型为空时不会提交，底部保持置灰并提示原因。

### 重新生成与修改提问

- 最后一条 AI 回答下方新增「重新生成」，丢弃该条回答后按同一上下文重新请求。
- 最后一条提问旁新增「修改」，可改写后重新发送：该消息之后的内容会被截断，之前的截图与 `@` 上下文引用保留；标题若仍为自动生成，会随新提问更新。
- 生成过程中上述入口自动隐藏，并提示「正在回答中，请稍候或先停止生成」。

### 滚动

- 修复流式输出时页面「瞬移」：旧实现每收到一个 token 就把长消息顶部对齐到视口顶部，看起来像跳了一下。
- 现在的规则：只有当你本来就在底部时，新内容才继续跟随，并按像素补齐差值而不是重排对齐；一旦手指上滑（或拖住列表），本轮生成期间不再自动滚动，点「到底部」才回到末尾。

### 其他

- 设置 → 关于 的版本号改为读取真实 `versionName`，不再写死 `1.0.0`。
