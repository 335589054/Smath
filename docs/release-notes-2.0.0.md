# Smath 2.0.0

**下载**：`dist/Smath-2.0.0-release.apk`（12,948,317 字节，SHA-256 `BA4678A195F4DE7CA872A6BD31B6C78663C625F4A95525978963568C09763132`）

系统要求：Android 8.0（API 26）及以上。1.5.0 及更早版本用的是 debug 签名，装 2.0.0 前请先卸载旧版，本地会话数据会被清空（导出 Markdown/ZIP 备份后再删）。

## 这次更新了什么

### 1. 复杂分支对话（大改动）

新建会话时可以在首页打开「复杂分支对话」开关。开启后：

- 顶部 `@` 按钮换成**分支图标**，点开是「对话拓扑」面板：一轮问答画成一个节点，节点之间自动连线。
- 节点上只显示问题的前 24 个字；**长按不动**看该轮问题与完整回答，**按住拖**可以调整节点摆放（离开会话后仍保留）。
- 单击选中，可多选：选 1 个节点＝从它新建分支；选 2 个及以上＝把它们的上游上下文合并，开一条新分支（会把拓扑关系一并交给模型）。
- 选完点「新建分支」，输入框上方会出现「正在创建新的分支」提示条，拓扑图里同时出现「正在编辑」的节点。
- 「删除节点」会连带删掉所有下游节点；如果这个节点还有下游，会先弹确认框说明影响范围。
- 「跳转」只显示当前分支的内容，不会串到别的分支去。

从别的分支切回来时，界面上只会出现当前路径上的问答，上下文也只按这条路径发给模型。

### 2. 图片编辑：裁剪 + 画笔

拍照或选图后进入编辑页，工具栏可在「裁剪」和「画笔」之间切换（默认裁剪）：

- 画笔颜色：红、白、蓝、黑；白色适合涂掉不需要的题目（粗细上限更大），其他颜色也保留可调细节。
- 粗细用滑杆调，随时撤销上一笔；切换工具不会丢掉已经画好的笔迹或裁好的框。
- 笔迹存的是原图归一化坐标，所以先画后裁、先裁后画都不会错位。

### 3. 截屏悬浮按钮（适合平板）

设置 → 「截屏悬浮按钮」：**打开开关的那一刻就会弹出录屏授权**，之后点悬浮球截图不再弹窗。点一下悬浮球：截取当前屏幕 → 以小窗打开 Smath → 直接进裁剪页。

> 注：Android 14 起同一个录屏授权只能建一次虚拟屏，所以实现改成「授权一次、常驻一个虚拟屏」。如果系统里撤销了录屏权限，悬浮球会提示「截屏还没有就绪，请到设置里重新打开」。

### 4. 检查更新

设置 → 「检查更新」会拿 GitHub 上最新的 tag 和当前版本比较（按段比较数字，`1.10.0` 大于 `1.9.9`）。有新版时可以直接下载并安装，首次会引导你打开「安装未知来源应用」权限。

下载源默认走 `gh-proxy.com` 镜像，也可以切换成 `gh-proxy.org` 或官方 GitHub。镜像失败会自动回退到官方 API。

### 5. 一个节点的分支也能建

上一版只有选中 2 个以上节点才能建分支，现在选 1 个就行——等于「从这一轮继续开一条新分支」。

## 已知限制

- 录屏授权时如果系统让你「共享一个应用」，只有那一个应用的画面会被截进来；想截任意界面请在授权弹窗里把「应用范围」改成「共享整个屏幕」。
- 符号引擎的性能边界没变：符号行列式 ≤ 6 阶、符号逆/秩 ≤ 4 阶、矩阵 ≤ 20×20。
